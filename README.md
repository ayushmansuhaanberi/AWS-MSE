# AyuGym - Gym and Fitness Website

## Project Objective
To create a simple and user-friendly gym website using HTML and CSS.

## Features
- Simple navigation bar
- Gym introduction section
- Workout cards with images
- Contact information
- Responsive layout for mobile screens

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open the `fitzone_gym_website` folder in VS Code.
3. Open `index.html` in a browser.
