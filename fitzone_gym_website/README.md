# FitZone Gym Website

A simple beginner-level Gym and Fitness website made using HTML and CSS.

## Features
- Home, About, Workouts and Contact sections
- Three workout cards with photos
- Simple red, white and dark colour theme
- Responsive layout for smaller screens
- Navigation links and a button that scrolls to the workout section

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Deployment
The website can be deployed on Vercel by importing this GitHub repository. No build command is required for this static website.
